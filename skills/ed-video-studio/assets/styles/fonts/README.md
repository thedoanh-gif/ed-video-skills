# Font đi kèm để chọn thay DINRoundOT

| Thư mục | Giấy phép (đọc từ chính file font) | Chép từ |
|---|---|---|
| montserrat, open-sans, josefin-sans | SIL Open Font License | font đã cài trên máy dựng bộ này |
| roboto, roboto-slab | Apache License 2.0 | font đã cài trên máy dựng bộ này |

Segoe UI và Constantia là font của Microsoft: **không chép vào skill**. `tao_mau.py` lấy thẳng từ `C:\Windows\Fonts` khi dựng, nên chỉ dùng được trên máy Windows.
DINRoundOT là font thương hiệu TH, nằm ở `series-kits/th-default/fonts/`, chỉ dùng cho tài liệu nội bộ.
Đã loại: Lato (thiếu 104 chữ tiếng Việt trên máy này), Bahnschrift (thiếu "ỷ").
