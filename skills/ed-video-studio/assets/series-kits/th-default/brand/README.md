# brand/: logo và nhận diện của series

Kit gốc **không kèm logo**. Người dùng gửi file một lần cho mỗi series, agent lưu vào đây:

| File | Yêu cầu |
|---|---|
| `logo.png` | PNG nền trong suốt, cao ≥ 240px (hoặc `logo.svg`) |
| `logo-white.png` | (nên có) bản trắng để đặt trên nền tối |

- Dùng ở: intro, khung `cta-outro` (biến `logo`: `assets/brand/logo.png`), thumbnail.
- Không tự lấy logo trên mạng, không tự vẽ lại logo.
- Logo TH chỉ dùng cho nội dung nội bộ TH.
