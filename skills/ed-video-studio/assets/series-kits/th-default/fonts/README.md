# Font DINRoundOT

8 file font thương hiệu TH (Light, Regular, Medium, Bold và các bản Italic). **Chỉ dùng cho nội dung nội bộ TH.**

Khai báo trong HyperFrames (chép file vào `hf/assets/fonts/`):
```css
@font-face { font-family: "DINRoundOT"; src: url("assets/fonts/DINROUNDOT-LIGHT.otf");   font-weight: 300; }
@font-face { font-family: "DINRoundOT"; src: url("assets/fonts/DINROUNDOT-REGULAR.otf"); font-weight: 400; }
@font-face { font-family: "DINRoundOT"; src: url("assets/fonts/DINROUNDOT-MEDIUM.otf");  font-weight: 500; }
@font-face { font-family: "DINRoundOT"; src: url("assets/fonts/DINROUNDOT-BOLD.otf");    font-weight: 700; }
```
